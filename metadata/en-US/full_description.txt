Autumn is a journalling and archiving app for Android.

It is not a planner and not a reminder app. It is a memory aid: log a titled note into the right year, month and category, then browse it back in chronological order.

* Fast capture. Pick a date, pick a category, type a title, submit.
* Creation order, not edit order. An entry written in March stays in March, however often you revise it.
* Local and offline. Plain Markdown files in a folder you own. No account, no sync service.
* Markdown editor with syntax highlighting, search and replace, and a customisable action bar.
